# TRABALHO FINAL (P2) - TESTE BASEADO EM DEFEITOS
### Repositório para a prova 2 de Manutenção de Software por Lucas Gabriel de Almeida Souza

## Sobre
Aqui estão todos os arquivos utilizados para realizar a prova.
Os mais importantes são:
- jstring.py = código-fonte original. O programa JString tem como propósito converter (o mais próximo possível) funções e operações da classe String do Java para o Python.
- jstring-test.py = casos de testes.
- relatorio.html = traz um relatório do processo inteiro de mutantes. Dados importantes para concluir o score.
